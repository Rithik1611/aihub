# cableCORE app notes

Facts verified in chats (newest first). Edit or delete freely.

- The app's global PROCESS lookup table PairColorTable contains the 10-pair sequence: elements 1-5 White with Blue, Orange, Green, Brown, Grey; elements 6-10 Red with Blue, Orange, Green, Brown, Grey; noCoded_1 equals the element number and noofCodes_1 equals 2. (evidence: Read-only LookupTable query for PairColorTable, plant ALL, segment ALL, 2026-11-11.; 2026-11-11)
- STRANDING dcResistance has a global ALL/ALL formula that reads conductorClass, conductorCSA, conductorType from plant (with layer.this fallback), uses plant.conductorStandard and plant.standard, looks up IEC resistance via maxConductorResistanceIEC 60228 for IEC 60228/60502-1/60227-5/IS 7098-1/IS 8130, uses UL-specific tables for UL 2464/2586, applies an IRAM 2178-2 300 mm² AL exception of 0.1, an (evidence: Read-only database result from FormulaProcessAttributes for processName STRANDING and attributeName dcResistance, 2026-11-10.; 2026-11-10)
- For design.update_plant_attributes, dropdown attributes must be sent as the option text string (for example value:"300", not numeric value 300); the route resolves and stores it in dropdown form. The design_id is the design version id. (evidence: design.update_plant_attributes route description; design.plant_attributes result for ENG-LV-7042 showing conductorCSA stored as valueDropdown/value text "300".; 2026-11-10)
- Submitting a design for approval records a pending DesignStatusFlow request and notifies reviewers, but leaves the design in its current workflow state; APPROVE or REJECT performs the state transition. (evidence: workflow.design_submit route description and workflow.design_review route description; backend workflow.service.ts submitDesignForApproval and validateDesignTransition source.; 2026-11-10)
